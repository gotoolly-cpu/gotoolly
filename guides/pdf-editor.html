Step-by-Step: Using the PDF Editor

Step 1: Upload Your PDF

What to do: Click the upload area or drag and drop your PDF file. The file loads directly into your browser's memory.

Why it matters: The upload is local (no network transfer), so even large PDFs load quickly. Files up to 25MB are supported.

Common mistake: Dragging a non-PDF file (like an image or Word document). Ensure your file has a .pdf extension.

Step 2: Select a Tool

What to do: Click a tool icon from the toolbar at the top. The active tool is highlighted in blue. Tools are grouped: Text, Image, Shapes (Rectangle, Rounded Rectangle, Circle, Ellipse), Connectors (Line, Arrow), Callout, Highlight, Redact, and Stamp.

Why it matters: The tool determines what kind of element you place on the canvas. You can switch tools at any time.

Step 3: Place or Draw Your Element

What to do: For most tools, click on the PDF canvas where you want the element. For shapes and connectors, click and drag to set the size. For Text and Callout, a text input appears — type your content, then click "Add" to place it.

Why it matters: Elements are placed at the clicked position and can be moved or resized after placement.

Step 4: Edit Properties

What to do: Click on any placed element to select it. The Properties panel on the right shows editable controls for position (X, Y), size (width, height), color, opacity, rotation, and text content.

Why it matters: Fine-tune your elements for precise placement. The Properties panel updates in real time as you drag elements on the canvas.

Step 5: Manage Layers

What to do: Use the Layers panel below the Properties panel to reorder, lock, or hide elements. Click the eye icon to hide an element, the lock icon to prevent accidental moves, or the up/down arrows to change layer order.

Why it matters: Layer order determines which elements appear on top. Lock and hide features prevent accidental edits to finished elements.

Step 6: Navigate Pages

What to do: Use the page navigation arrows at the bottom of the canvas to move between pages. Add different elements to each page. The page counter shows your current position.

Why it matters: Each page has its own independent set of elements. You can add a watermark to page 1 and a signature to page 3.

Step 7: Export

What to do: Click the "Apply & Download" button when you're finished. The editor exports all your elements into a new PDF and downloads it automatically. The session resets so you can upload another file.

Why it matters: The export preserves your PDF's original quality and dimensions. All elements are embedded at their correct positions on each page.

Tool-by-Tool Guide

Text Tool

Click the canvas to open a text input. Type your content (supports multi-line), adjust font size and color, then click "Add" to place. The text element supports word wrapping — long lines break automatically to fit within the width you set. Drag the element to reposition, use corner handles to resize the bounding box, and use the rotation handle to angle the text.

Image Tool

Click the canvas to open a file picker. Select a PNG, JPG, GIF, or WebP image. The image is placed at the clicked position. Drag to reposition and use corner handles to scale. Images are cached locally so switching pages doesn't lose them.

Shape Tools (Rectangle, Rounded Rectangle, Circle, Ellipse)

Select a shape tool, then click and drag on the canvas to draw. The shape is created with your default fill and stroke colors. Use the Properties panel to change fill color, stroke color, opacity, and rotation after placement.

Line & Arrow Tools

Click and drag to set the length and angle. Lines and arrows use the stroke color and width. Drag the endpoints to adjust after placement. Use the rotation handle for precise angles.

Callout Tool

Click the canvas to open a text input with a background color picker. Type your message and click "Add". The callout appears as a speech bubble with your text inside. The background color defaults to a light yellow; you can change it to any color.

Highlight Tool

Click to place a semi-transparent colored rectangle. Defaults to a yellow highlight (#fef08a). Use the Properties panel to change the color and opacity. Ideal for marking sections of text in the underlying PDF.

Redact Tool

Click to place a solid black rectangle. This is used to permanently hide sensitive information. The element is fully opaque by default. Position and resize it to cover the content you want to redact.

Stamp Tool

Click the Stamp icon to open the stamp picker. Choose from 7 pre-made stamps: Approved, Denied, Draft, Confidential, Final, Not Approved, or Experimental. Click a stamp to place it on the canvas. Each stamp has a distinct color and style.

Best Practices for Great Results

Tip: Place elements page by page. Navigate to the correct page before adding elements. Each page has its own independent element set.

Tip: Use the Properties panel for precision. Instead of dragging blindly, select an element and type exact X, Y, width, and height values for pixel-perfect placement.

Tip: Lock finished elements. Once an element is positioned correctly, lock it in the Layers panel to prevent accidental moves while working on other elements.

Tip: Use Undo liberally. Every action is tracked. If something goes wrong, press Ctrl+Z to step back.

Tip: Redact carefully. Redaction covers content with a solid black box. Make sure it fully covers the sensitive area by resizing it appropriately.

Common Mistakes to Avoid

Mistake 1: Adding Elements on the Wrong Page

The Problem: You place text or shapes on page 1 when you meant page 3.

Fix: Always check the page counter at the bottom before placing elements. Use the page arrows to navigate to the correct page first.

Mistake 2: Forgetting to Export

The Problem: You close the browser tab without exporting. All changes are lost.

Fix: Click "Apply & Download" when you're satisfied. The download starts automatically.

Mistake 3: Text Overflow

The Problem: Your text element extends beyond the page boundary or overlaps other content.

Fix: Use the resize handles to adjust the text bounding box. For multi-line text, the word wrapping adjusts automatically when you change the width.

Mistake 4: Elements on Top of Each Other

The Problem: You can't select an element because another one is on top of it.

Fix: Use the Layers panel to select elements by name, or use the up/down arrows to change layer order. You can also hide top elements temporarily.

Can I undo changes in the PDF Editor?

The maximum file size is 25 MB per file. For larger files, consider compressing the PDF first using the PDF Compressor tool.
