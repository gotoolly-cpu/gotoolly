Frequently Asked Questions

What is a favicon?

A favicon is the small icon displayed in browser tabs, bookmarks, and mobile home screens. It helps users identify your website. A proper favicon bundle includes multiple sizes for different devices and contexts.

What files are included in the download?

The bundle includes favicon.ico (16/32/48px), PNGs from 16x16 to 512x512, apple-touch-icon.png, android-chrome icons, mstile, safari-pinned-tab.svg, site.webmanifest, browserconfig.xml, and a README with installation instructions.

How do I install the favicon on my website?

Upload all files to your website root directory. Add the HTML tags from the included README to your <head> section. The tool provides ready-to-use code for all platforms.

What image formats work best?

Square images work best for favicons. PNG and JPG are both supported up to 10 MB. The tool automatically crops and resizes to the required dimensions.
