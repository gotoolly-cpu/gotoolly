FAQ

Common questions about the Meta Description Preview tool.

What is the ideal meta description length?

The optimal meta description length is 150-160 characters. Google typically displays up to 150-160 characters before truncating.

Why does my snippet show an ellipsis?

Google truncates titles over roughly 60 characters and descriptions over roughly 160 characters. The tool flags these points so you can fix them.

Is my data stored anywhere?

No. All processing happens entirely in your browser. Your title, URL and description never leave your device.
