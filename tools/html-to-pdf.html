Frequently Asked Questions

What HTML features are supported?

Headings, paragraphs, lists, tables, bold, italic, underline, and inline styles. External CSS/JavaScript, web fonts, and complex CSS layouts are not supported.

Can I upload an HTML file?

Yes. You can upload .html or .htm files, or paste HTML code directly into the textarea.

What page sizes are available?

A4, Letter, and A3 page sizes are supported, with portrait or landscape orientation and narrow, normal, or wide margins.

Are my HTML contents uploaded?

No. Everything is processed entirely in your browser. Your HTML never leaves your device.

Are images supported?

Images are supported only if embedded as data URIs (base64). External image URLs are not loaded.

What happens if my HTML is very long?

Long content is split across multiple pages automatically, and the tool shows the total number of pages and file size before you download.
